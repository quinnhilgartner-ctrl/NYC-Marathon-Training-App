# NYC Marathon Training Plan (2026)

An interactive 18-week marathon training checklist for the NYC Marathon on **Sunday, November 1, 2026**.

## Usage

Open `index.html` in any browser — no install required. Click any workout to check it off. Progress is saved automatically in your browser (localStorage).

## Plan Overview

- **Dates**: June 28 – October 31, 2026 (18 weeks, Sun–Sat)
- **Sunday**: Recovery day
- **Monday**: Mid/easy run (3–6 mi)
- **Tuesday**: Leg day (strength A)
- **Wednesday**: Track workout
- **Thursday**: Leg day (strength B)
- **Friday**: Arm workout
- **Saturday morning**: Long run

## Features

- Check off all 126 workouts + race day
- Auto-saves progress (localStorage)
- Highlights the current week and today's workout
- Progress stats: workouts done, % complete, long-run miles, race countdown
